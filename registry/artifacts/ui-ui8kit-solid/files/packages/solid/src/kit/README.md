# UI8Kit (Solid)

This tree is the Solid-only subset of UI8Kit. `@ui8kit/codegen` emitted
the hosts. Hand-edit only `*.variants.json` and `utils/`. Generated files
say `DO NOT EDIT`.

| Import | Path |
| --- | --- |
| Atoms | `$ui8kit/ui` → `index.solid.ts` |
| Helpers | `$ui8kit/utils` (`cn`) |

React, Vue, Svelte, templ, Twig, Latte, and Go hosts are not vendored here.
The Wails app does not keep a second copy under `src/kit`.
